# Changelog

## 0.1.0

- Standalone Termux CLI and interactive menu.
- APK manifest/permission/ABI/engine reports, extraction, comparison, assets, decoding, Java decompilation, rebuilding and projects.
- Private key creation, alignment, v1/v2/v3 APK signing, verification, and signing split sets with one key.
- Recursive source/native search and bounded automatic marker triage.
- Previewable text/XML/byte patch recipes with match/hash preconditions and copied outputs.
- DEX integrity/class reports, ELF reports, symbols, disassembly, strings, byte patterns, and equal-length file patches.
- Optional installed-package export, installer handoff, log snapshots, accessible process maps and module snapshots.
- Read-only workspace-restricted MCP tools for local agents, including exported native function evidence.
- Ghidra/IDA provider adapters and exporter scripts, with explicit local/SSH invocation.
- Termux Frida package integration, runtime modules/exports, custom scripts, tracing, and loopback server helper.
